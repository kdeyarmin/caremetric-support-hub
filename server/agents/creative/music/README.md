# Royalty-free music for creative videos

Optional. Drop royalty-free tracks here (MP3, M4A, AAC or WAV) that CareMetric has the right to use in paid ads, and commit them. Each
video picks one by its asset id and lays it under the picture with a half-second fade in and a one-second fade out. With no track here,
videos are silent (captions carry the words either way).

Only add music whose license covers paid social and display advertising without attribution in the ad. Keep a note of each track's
source and license next to it (for example `track-name.LICENSE.txt`).
